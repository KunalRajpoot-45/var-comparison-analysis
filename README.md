# Empirical Risk Management: Comparative Analysis of Value at Risk Models
## How to Run

1. Clone the repository:

```bash
git clone https://github.com/KunalRajpoot-45/var-comparison-analysis.git
cd var-comparison-analysis
```

2. Install the required Python libraries:

```bash
pip install numpy pandas scipy matplotlib seaborn yfinance jupyter
```

3. Start Jupyter Notebook:

```bash
jupyter notebook
```

4. Open `VaR_Analysis.ipynb`.

5. Run the notebook cells sequentially from top to bottom.

The notebook downloads the required AAPL market data using `yfinance`, so an active internet connection is required.
